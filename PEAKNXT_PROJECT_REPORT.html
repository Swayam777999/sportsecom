CHAPTER 1: PROBLEM STATEMENT

1.1 Problem Statement

Across university athletic departments, grassroots sports academies, competitive training centers, and fitness communities throughout the Thane and Mumbai metropolitan region, aspiring athletes, students, and coaches face acute friction in procuring authentic, match-grade sporting goods. Unlike casual lifestyle retail, sports equipment is strictly bound to physiological parameters, court surfaces, skill grades, and safety regulations.

Traditional e-commerce platforms and local brick-and-mortar sports suppliers suffer from critical operational bottlenecks:

  • Severe Equipment Mismatch & Injury Vulnerability: Novice and developing athletes lack domain guidance, frequently purchasing incompatible gear (e.g., using non-marking indoor badminton shoes on outdoor concrete courts, or bats with inappropriate willow grain densities), leading to joint strain, equipment breakage, and elevated injury rates.
  • Static, Low-Immersion Shopping Interfaces: Mainstream sporting goods websites rely on flat, lifeless product images that fail to capture the adrenaline and athletic focus of sports, driving high cart abandonment among athletic consumers.
  • Opaque Order Logistics for Competition Schedules: For athletes and sports teams preparing for scheduled inter-collegiate tournaments, generic delivery estimates lack milestone granularity, causing teams severe anxiety over whether match equipment will arrive prior to tournament fixtures.
  • Absence of Verified Field-Test Feedback: Standard product reviews are flooded with unverified ratings that fail to communicate critical athletic criteria such as ball bounce retention, seam durability, string tension stability, or ergonomic grip resilience.
  • Manual Invoicing and Institutional Friction: College athletic clubs and sports academies require standardized, verifiable digital tax invoices with instant authenticity checks for institutional reimbursement.

PeakNXT is engineered as a modern, full-stack athletic commerce platform to resolve these challenges. It establishes a centralized, high-performance web ecosystem combining an AI-driven smart sports matchmaker ("PeakGear AI"), a dynamic live moving sports video background with kinetic HUD telemetry, an authentic 4-milestone order progression tracker, verifiable digital tax invoices with QR stamps, and a verified athlete review system.

1.2 Sustainable Development Goals (SDGs)

SDG 3 – Good Health and Well-Being
Target 3.4 & 3.5: PeakNXT directly fosters physical fitness, athletic engagement, and cardiovascular health by democratizing access to certified, match-grade equipment. Target 9.5: PeakNXT demonstrates modern full-stack web computing principles by integrating a type-safe Kotlin/JVM Spring Boot backend, a reactive React 18 TypeScript frontend, and Google Cloud Firestore NoSQL storage, modeling high-speed, scalable digital infrastructure for athletic commerce.

SDG 8 – Decent Work and Economic Growth
Target 8.2 & 8.3: By offering transparent inventory management, accurate order delivery milestones, and instant institutional invoice generation, PeakNXT streamlines retail logistics for grassroots coaches, independent sports academies, and equipment manufacturers.

CHAPTER 2: INTRODUCTION

2.1 Introduction

PeakNXT is a modern, responsive web application engineered to bridge the operational divide between competitive athletes, college teams, sports academies, and pro-grade equipment manufacturers. Developed as a Web & Mobile Development (WMD) Laboratory Mini-Project for the Department of Computer Science & Engineering (Artificial Intelligence & Machine Learning) at A. P. Shah Institute of Technology, the platform models an enterprise-ready, three-tier client-server architecture with cloud data persistence, role-based state tracking, and reactive UI paradigms.

The application allows users to explore an expansive catalog of 40 certified equipment items across 9 Olympic and team sports categories, receive AI-curated gear recommendations, experience a live sports video background with user-controllable telemetry HUD, place orders, monitor 4-stage delivery milestones, and contribute verified athlete field-test ratings.

2.2 Pro-Grade Sports Equipment Classifications

To ensure athletic suitability, safety certification, and streamlined browsing, PeakNXT categorizes its catalog into 9 specialized sports divisions:

  • Fitness & Strength: Commercial-grade Olympic barbells, cast-iron hex dumbbells, competition kettlebells, adjustable benches, and multi-functional power towers.
  • Basketball: FIBA-approved composite leather game balls, high-abrasion outdoor court balls, carbon-torsion basketball sneakers, and regulation-height net rims.
  • Running & Athletics: Marathon carbon-fiber plated road shoes, responsive trail-running sneakers, running hydration vests, and digital athletic stopwatches.

  • Badminton: Ultra-light high-modulus graphite rackets, goose-feather tournament shuttles, high-tension braided strings, and thermal racket bags.

CHAPTER 3: TECHNOLOGY & TOOLS

3.1 Application Technologies

  • React.js 18: Declarative component-based frontend framework utilizing functional components, custom hooks (useState, useEffect, useRef, useContext), and synthetic event pipelines.
  • TypeScript (v5.x): Strongly typed superset of JavaScript providing static type checking across API responses, product schemas, cart states, and review models.
  • Vite 5: Next-generation frontend build tooling offering instantaneous Hot Module Replacement (HMR) and optimized Rollup asset bundling.
  • Kotlin on JVM 17: Server-side execution runtime offering null safety, immutable data classes, extension functions, and concise object modeling.
  • Spring Boot 3.3.5: Enterprise-grade Java/Kotlin framework powering dependency injection, embedded Tomcat server execution, and RESTful routing.
  • Google Cloud Firestore: Cloud-hosted NoSQL document database providing low-latency collection queries, automatic horizontal scaling, and sub-second updates.
  • Vanilla CSS Athletic Design System: Custom-engineered styling using CSS Custom Properties (variables), Neon Volt (#00f076) accents, Obsidian Slate (#070a10) dark surfaces, and fluid flexbox/grid architectures without bulky UI frameworks.
  • HTML5 Canvas 2D Telemetry Engine: Custom mathematical particle physics rendering cursor-reactive kinetic points over the video background.

3.2 Development and Testing Tools

  • Visual Studio Code & IntelliJ IDEA: Multi-language development environments configured with Kotlin JVM plugins, Gradle tooling, and TypeScript language servers.
  • Gradle (Kotlin DSL): Automated build automation tool managing Spring Boot dependencies, JVM compilation, and test execution.

3.3 Development Methodology and System Architecture

PeakNXT was developed adhering to a three-tier decoupled client-server architecture. The user initiates interaction through the responsive browser client, which communicates asynchronously via HTTP/JSON REST requests to the Spring Boot application running on port 8080. The backend validates requests and interfaces with Cloud Firestore via the Google Cloud Service Account SDK.

PEAKNXT SYSTEM ARCHITECTURE FLOW +-----------------------------------------------------------------+ | React 18 + TypeScript Client (Port 5173) | | | | [PeakGear AI] [Live Video HUD] [Reactive Cart] [Reviews] | +-----------------------------------------------------------------+ | HTTP REST / JSON Requests | v +-----------------------------------------------------------------+ | Kotlin + Spring Boot 3.3.5 API (Port 8080) | | | | ProductController OrderController SecurityConfig | | | | | | | ProductService OrderService CORS Filter | +-----------------------------------------------------------------+ | Firebase Admin SDK (OAuth2) | v +-----------------------------------------------------------------+ | Google Cloud Firestore NoSQL | | | | [products collection] [orders collection] | | (40 certified items) (#PKX-XXXX invoices) | +-----------------------------------------------------------------+

The system workflow ensures separation of concerns: the frontend manages UI rendering, responsive layouts, and user interactions; the Spring Boot backend enforces business validation, pricing integrity, and security policies; and Cloud Firestore provides scalable cloud persistence.

CHAPTER 5: CONCLUSION

5.1 Learnings from Web and Mobile Application Development

Through the end-to-end design, implementation, and optimization of PeakNXT, the project developer acquired comprehensive theoretical and practical competencies across modern web engineering:

  • Full-Stack Client-Server Decoupling: Gained deep expertise structuring clean JSON API contracts between a React 18 TypeScript frontend and a typed Kotlin / Spring Boot 3.3.5 microservice.
  • Cloud NoSQL Document Modeling: Learned non-relational document structuring, collection indexing, and atomic write operations within Google Cloud Firestore.
  • Advanced CSS Stacking & Z-Index Management: Resolved complex CSS stacking context challenges by decoupling negative z-index video layers from high-priority floating HUD control overlays.
  • Hardware-Accelerated Web Media: Implemented seamless HTML5 video looping combined with interactive HTML5 2D Canvas particle rendering without degrading DOM paint performance.
  • State Management & Persistence: Mastered multi-tier state coordination using React Context API, custom hooks, and localStorage synchronization for user themes, carts, and reviews.

5.2 Conclusion

PeakNXT successfully delivers an innovative, pro-grade sports commerce web platform that resolves the inefficiencies and static nature of generic sporting goods retail. By unifying AI-driven equipment matchmaking, real-time live video ambience, interactive order tracking, digital tax invoicing, and verified athlete reviews, the application elevates sports equipment procurement into an immersive, authentic experience. The project demonstrates the practical application of advanced web computing principles, cloud persistence, and reactive user interface design in alignment with United Nations Sustainable Development Goals.
